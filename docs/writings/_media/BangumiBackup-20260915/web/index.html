Bangumi Takeout Web

纯前端备份 · 数据保存在浏览器本地缓存

使用说明

功能

  • 备份：将 Bangumi 收藏列表导出为 takeout.json 文件。
  • 导入旧数据：上传之前导出的 takeout.json，其数据会写入本地缓存，用于后续备份时复用，减少 API 调用。
  • 导出备份：不重新备份，直接把本地缓存的备份数据导出为 takeout.json。
  • 支持断点续传：遇到网络波动、Bangumi API 调用过多，或手动停止备份的情况，只要缓存未过期，均可从断点继续备份。

缓存与清理

  • 备份数据缓存有效期：180 天（缓存生成后的 180 天内再次备份会直接复用，不会重新调用 API）。

耗时说明

以下估算基于：约 1500 条收藏、请求间隔 700ms、每条平均需要 9 次 API 调用（1 次 subject + 约 7 次 episode type + 1 次 progress），且未命中任何本地缓存。 实际耗时随收藏量、间隔设置、本地缓存命中率而变。

  • 首次使用：需要拉取收藏列表并逐条补充详情。按上述前提，约 2–3 小时。如果配合 BGM 数据命中大部分 subject / episode，可缩短到十几分钟到半小时。
  • 首次备份后再次备份：大部分条目会命中缓存，通常几秒到几分钟即可完成。
  • 点击「刷新 BGM 数据索引」后：下次备份时会重新按需下载分片，视收藏量通常多花几分钟。

其他

本项目由 bangumi-takeout-py 启发，导出的 takeout.json 格式与该项目一致，如需要 html / csv 格式可直接使用该项目的 generate_html.py 或 generate_csv.py 脚本。
