# 使用説明

右側のウィジェットの機能は：

- モード切替：自動 / ライト / ダークモード
- テーマ切替：クリックしてテーマを選択
- テーマカラー選択：クリックして色を選択
- 文字サイズ切替：本文サイズを五段階から選択可能
- コメント：クリックしてコメント欄へ移動
- 桜吹雪：オン / オフ
- Live 2d キャラ：オン / オフ（デスクトップ版のみ）
- ウィジェットコントロール：展開 / 折りたたみ
- ページプログレス：クリックして中央の数字の表示 / 非表示を切り替え
- トップへ戻る

このブログでは以下のショートカットキーを提供する。いずれも <kbd>B</kbd> と組み合わせて使用する。

- 検索（目次ページ以外でのみ有効）：<kbd>/</kbd>
- 前のページ / 次のページ / ページ番号入力（目次ページでのみ有効）：<kbd>←</kbd> / <kbd>→</kbd> / <kbd>P</kbd>
- モード切替：<kbd>M</kbd>
- テーマ切替：<kbd>T</kbd>
- テーマカラー選択：<kbd>C</kbd>
- 文字サイズ切替：<kbd>F</kbd>
- プリセット選択（テーマ切替／テーマカラー選択／文字サイズ切替の選択肢が開いている場合のみ有効）：数字キー <kbd>1</kbd>～<kbd>0</kbd>
- コメント：<kbd>L</kbd>
- 桜吹雪：<kbd>S</kbd>
- Live 2D キャラ：<kbd>G</kbd>
- ウィジェットコントロール：<kbd>W</kbd>
- ページプログレスの数字表示（Swiss テーマ以外でのみ有効）：<kbd>N</kbd>
- トップへ戻る：<kbd>↑</kbd>
