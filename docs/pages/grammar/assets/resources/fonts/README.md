# 字体目录

将字体文件放到此目录，命名与 `assets/css/fonts.css` 中一致，即可自动生效。

约定文件名：
- `ui-regular.woff2` / `ui-bold.woff2`  界面字体（含中文）
- `la.woff2`    拉丁语
- `grc.woff2`   古希腊语
- `he.woff2`    圣经希伯来语
- `sa.woff2`    梵语（天城文）
- `mnc.woff2`   满语（传统蒙文）
- `ja.woff2`    日语
- `zh-cls.woff2` 古汉语

缺少字体文件时，浏览器回退到 `--ff-ui` 中的后备字体，功能不受影响。
