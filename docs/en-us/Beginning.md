# Instructions for Use

The floating widgets on the right are, from top to bottom:

- Mode switcher: Auto / Light / Dark mode
- Theme picker: Click to choose theme
- Theme color picker: Click to choose color
- Font size switcher: Click to choose from five available sizes
- Comment: Scroll to comment on click
- Cherry blossom switcher: Turn on / off
- Live 2d figure switcher: Turn on / off (Available only on Desktop)
- Widget controller: Expand / Collapse
- Page progress: Show / Hide progress number in the middld of the progress bar on click
- Back to the top

This site provides the following keyboard shortcuts, all of which are used in combination with <kbd>B</kbd>:

- Search (only available on non-toc pages): <kbd>/</kbd>
- Previous page / Next page / Enter page number (only available on toc pages): <kbd>←</kbd> / <kbd>→</kbd> / <kbd>P</kbd>
- Mode switcher: <kbd>M</kbd>
- Theme picker: <kbd>T</kbd>
- Theme color picker: <kbd>C</kbd>
- Font size switcher: <kbd>F</kbd>
- Preset selection (only available when the options for theme picker / theme color picker / font size switcher are open): number keys <kbd>1</kbd> to <kbd>0</kbd>
- Comments: <kbd>L</kbd>
- Cherry blossom switcher: <kbd>S</kbd>
- Live 2D figure switcher: <kbd>G</kbd>
- Widget controller: <kbd>W</kbd>
- Page progress number display (only available for non-Swiss themes): <kbd>N</kbd>
- Back to the top: <kbd>↑</kbd>
