# 使用说明

右侧的小组件从上至下依次为：

- 模式切换：自动 / 浅色 / 深色模式
- 主题选择：点击选择主题
- 主题色拾色器：点击选择颜色
- 字号切换：提供五种正文字号以供选择
- 评论：点击跳转到评论区
- 樱花特效：打开 / 关闭
- Live 2d 小人：打开 / 关闭（仅桌面端）
- 小组件控制：展开 / 收起
- 本页进度：点击切换中间数字显示 / 隐藏
- 回顶部

本站提供以下快捷键，均需要与 <kbd>B</kbd> 组合使用：

- 搜索（仅在非目录页有效）：<kbd>/</kbd>
- 上一页 / 下一页 / 输入页码（仅对目录页有效）：<kbd>←</kbd> / <kbd>→</kbd> / <kbd>P</kbd>
- 模式切换：<kbd>M</kbd>
- 主题选择：<kbd>T</kbd>
- 主题色拾色器：<kbd>C</kbd>
- 字号切换：<kbd>F</kbd>
- 预设选择（仅在主题选择 / 主题色拾色器 / 字号切换的选项开启时有效）：数字键 <kbd>1</kbd> 至 <kbd>0</kbd>
- 评论：<kbd>L</kbd>
- 樱花特效：<kbd>S</kbd>
- Live 2d 小人：<kbd>G</kbd>
- 小组件控制：<kbd>W</kbd>
- 本页进度数字显示（仅对非 Swiss 主题有效）：<kbd>N</kbd>
- 回顶部：<kbd>↑</kbd>
